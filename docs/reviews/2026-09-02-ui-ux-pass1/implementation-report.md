## Left under "Not built" (deliberate, not part of C-01…C-29)

- **"Total P&L" naming.** The `ux-reviewer` asked for Asset Detail's "Total return" and the Portfolio bar's "P&L" to both adopt the glossary's "Total P&L". The consensus deliberately kept both names (C-15 only unified the *measure* label to MWR), so this is left as an owner's-call follow-up.
- **Transactions table breakpoint.** Mobile MUX-02 names the same `sm` table/card switch on the Transactions log that C-13 fixed on Portfolio. Not a consensus entry, so untouched.
- **Bulk editor's grid on a phone.** MUX-10's "import-first screen" is a pass-2 item; only C-19's chrome and the one-row header shipped.
- **Shared `Toggle` hover == pressed styling** (`components/ui/toggle.tsx`) — a primitive-level change that would touch every toggle in the app.
- **Portfolio group header shows no % in Total mode** — by design (a group's total P&L has no single denominator), flagged by the reviewer, left as-is.
- **The "Also noted" list from the consensus** (owner's call) and every **pass-2 mobile** item beyond the six interaction addenda.
- **Performance page** — feature-flagged off and frozen; not touched (`TimeRangeSelector` is shared with it and still compiles).
